      About

      Welcome to GBEMU, a Game Boy / Game Boy Color emulator running directly in your browser.

      Upload a .gb or .gbc ROM using the sidebar, then load it from the list.

      Save States let you capture and restore the running game's exact state - name one with the sidebar's Save State button, then load, overwrite, or delete it from the Save States list. They persist in this browser across page reloads, same as uploaded ROMs.
